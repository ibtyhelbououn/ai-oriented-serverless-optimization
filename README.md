# AI-Oriented Serverless Computing Optimization

Research implementation developed as part of my MSc thesis in Information Technologies at Altınbaş University.

## Overview

This repository contains Python implementations and experimental prototypes developed during my MSc research on AI-oriented optimization of serverless computing systems.

The work investigates algorithmic approaches to task scheduling, workload partitioning, resource allocation, and load balancing in simulated serverless environments. Both AI/ML-based and conventional optimization approaches were explored and evaluated experimentally.

The repository accompanies the MSc thesis:

**AI-Oriented Serverless Computing Optimization**

## Research Areas

The implementation includes experiments covering:

- AI/ML-based optimization approaches
- Non-AI optimization and scheduling approaches
- Workload partitioning using K-means
- Neural-network-based resource allocation
- Reinforcement learning and Q-learning
- Hybrid reinforcement learning and backpressure scheduling
- Round-Robin scheduling
